# Business Rules

| Rule ID | Rule |
|---|---|
| BRULE-001 | A user must have a registered account before successful login. |
| BRULE-002 | Registration data must pass input-format validation before being saved. |
| BRULE-003 | Staff must choose a table in an available/empty state before starting a food order. |
| BRULE-004 | If the selected table is already in use, staff must select another table. |
| BRULE-005 | If a selected food item is unavailable/out of stock, the system must notify the user and require another selection. |
| BRULE-006 | Inventory updates must be validated before new ingredient/inbound/outbound information is saved. |
| BRULE-007 | After inbound stock, inventory quantity/value is updated; after outbound stock, inventory quantity/value is updated. |
| BRULE-008 | Payment must use a supported/valid payment method; invalid/unsupported payment selection requires another method. |
| BRULE-009 | Invoice/payment information is stored after payment processing. |
| BRULE-010 | Only management may view employee profile/personal information. |
| BRULE-011 | Financial statistics can be selected by day, month, or year. |
