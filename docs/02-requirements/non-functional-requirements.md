# Non-Functional Requirements

Unlike many academic reports, the source explicitly includes a small NFR table.

| ID | Category | Requirement |
|---|---|---|
| NFR-UI-01 | GUI | The interface should be user-friendly, multilingual, and highly interactive. |
| NFR-OPS-01 | Operation | The system must run on desktop computers, laptops, and mobile devices. |
| NFR-OPS-02 | Compatibility | The system must run on all web browsers. |
| NFR-PERF-01 | Performance | User-system interaction should not exceed 2 seconds. |
| NFR-AVL-01 | Availability | The system should operate 24/7. |
| NFR-SEC-01 | Security | Only management may view employee profiles/personal information. |
| NFR-PRIV-01 | Privacy | The system must comply with laws concerning user privacy. |
