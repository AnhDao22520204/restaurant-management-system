# Stakeholders and Business Actors

| Stakeholder / Actor | Documented involvement |
|---|---|
| Restaurant Manager / Admin | Manages employees, menu, tables, inventory-related information, revenue/profit, permissions |
| Employee / Service Staff | Login, table/order operations, menu lookup, ingredient/inventory operations |
| Cashier | Invoice creation/maintenance, menu lookup, employee lookup, revenue statistics |
| Chef / Kitchen | Mentioned in interview/survey context and represented in the system context/use-case diagram; detailed standalone use case is not specified |
| Customer | Provides ordering/payment needs; not modeled as a primary system actor in the detailed actor table |
